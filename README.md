# DSA Lab 4

This repository contains three C++ tasks based on linked lists.

## Tasks

### Task 1: Music Playlist
Implements a music playlist using a doubly linked list. Each node stores song information and supports moving forward and backward through the playlist.

### Task 2: Josephus Problem
Simulates the Josephus problem using a circular singly linked list. People are removed in sequence until one survivor remains.

### Task 3: Binary Arithmetic
Uses a doubly linked list to store binary numbers and perform operations such as complements, addition, and multiplication.

## Compile and Run

Compile and run each task separately:

```bash
g++ -std=c++17 task1.cpp -o task1
./task1

```bash
g++ -std=c++17 task2.cpp -o task2
./task2

```bash
g++ -std=c++17 task3.cpp -o task3
./task3

Requirements
A C++ compiler such as g++ is required.
